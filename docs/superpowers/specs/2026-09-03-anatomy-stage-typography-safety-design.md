# 身体定位页：解剖舞台、字体与安全说明改版设计

日期：2026-09-03

## 1. 目标

本次改版解决五个相互关联的问题：页面正文和操作文字偏小；“专业解剖”被放在 3D 模型内部，层级不清；身体定位图与专业解剖重复且分散；关节编号遮挡肌肉图；安全说明缺少可执行内容。

完成后，用户应当能在页面中央直接切换“3D 人体”和“专业解剖”，在专业解剖中选择男/女、正面/侧面/背面并缩放人体；所有可选肌肉都保留明确的文字入口；关节图上的标注不遮挡关键肌肉；核心文字在常规尺寸及浏览器放大 200% 时仍清楚、可操作；安全说明能回答“怎样开始、何时停止、何时应先就医评估”。

## 2. 已确认的产品决定

- “3D 人体”和“专业解剖”是同一级模式，使用页面中央顶部的分段切换器，一次显示一种模式。
- 原右侧的身体正背面定位图并入“专业解剖”模式，右侧栏不再重复显示小人体。
- 专业解剖支持男生、女生切换，也支持正面、侧面、背面切换。
- 专业解剖支持放大、缩小、复位；切换性别或视角时保留当前选中目标，切换动作时复位到适合查看的比例。
- 人体图的直接点击用于快速选择；完整的肌肉文字按钮始终保留，解决深层肌肉、重叠肌肉或图形库未提供独立点击区域的问题。
- 前、侧、后是全身解剖视角，不只用于局部膝、肩、踝关节图。
- 局部关节图继续使用现有插图，但把大号编号移到图外，以细引导线和小锚点对应图中位置。
- 安全说明是页面中的真实内容区，而不是只有一句免责声明的页脚。

## 3. 页面结构

桌面端仍保持左、中、右三栏，但重新划分职责：

1. 左栏：当前任务、步骤进度和已选信息摘要。
2. 中栏：主要视觉与定位舞台。顶部是“3D 人体 / 专业解剖”模式切换，下方显示对应人体；工具栏承载视角、性别、缩放与复位。
3. 右栏：完整定位控件、身体感觉、安全筛查和匹配动作。这里使用文字选项与状态提示，不再放重复的小人体。

窄屏按“步骤摘要 → 中央舞台 → 文字定位与安全 → 推荐动作”的顺序纵向排列。布局使用内容驱动的最小高度，不再依赖会裁掉内容的固定高度。

## 4. 中央双模式舞台

### 4.1 3D 人体

保留现有 3D 人体的旋转、正背面和复位能力。专业解剖入口从 3D 工具栏移除，改为舞台顶部的一级模式切换。这样用户不会误以为专业解剖只是 3D 的一个弹窗工具。

### 4.2 专业解剖

专业解剖不再使用模态弹窗，直接占用中央主舞台。工具区分为三组：

- 人体类别：男生、女生；默认沿用当前男性人体，以保持旧页面的初始行为。
- 观察方向：正面、侧面、背面。
- 查看比例：缩小、当前百分比、放大、复位；限制最小和最大比例，避免人体缩没或放大后无法找回。

正面和背面继续使用当前解剖组件提供的男女模型。该组件只提供正背面，因此侧面采用项目自有的简化教育插图，并在透明交互层上定义身体大区。侧面图不宣称能够精确展示每一块深层肌肉；完整肌肉按钮是选择能力的最终保障。禁止启用仓库中仅供本地审计、授权范围不适合生产分发的旧 GLB 解剖模型。

缩放只改变人体画布，不改变工具栏和文字按钮大小。放大后可在受限画布中平移查看，复位恢复居中。键盘用户可通过按钮完成所有选择，不依赖拖拽或图形热区。

### 4.3 点击完整性

人体图的热区可能同时对应多块肌肉。处理规则如下：

- 唯一命中时直接选中目标。
- 多个候选共用热区时，在舞台旁显示候选按钮，由用户明确选择。
- 组件没有独立热区的目标，仍能从“本区域全部肌肉”按钮列表中选择。
- 切换性别、前侧后视角不会清空已选目标；若当前视角不显示该目标，状态区仍明确显示“已选择”，并提示切换到更适合的视角查看。

这样可把“图上点得到”作为效率增强，而不是唯一入口。

## 5. 局部关节图标注

膝、肩、踝继续展示现有局部插图。现有 44 px 编号圆会遮住肌肉纹理，改为以下结构：

- 图中只保留约 10–14 px 的锚点，不覆盖主要解剖区域。
- 编号和肌肉名称放到插图左右两侧或下方的独立按钮区。
- 每个按钮通过细引导线连接锚点；移动端取消交叉引导线，改为按编号排列的双列/单列按钮。
- 选中态同时高亮图中锚点与外部按钮，悬停不是理解对应关系的必要条件。

前、侧、后全身切换属于专业解剖舞台；局部关节图只负责补充更细的位置关系，二者不混淆。

## 6. 字体层级与页面定位

采用以浏览器默认 16 px 为基准的 `rem` 字体层级：

| 用途 | 建议范围 | 使用位置 |
| --- | --- | --- |
| 页面主标题 | 2–3 rem（32–48 px） | 动作库标题、核心数量 |
| 一级区块标题 | 1.5–1.75 rem（24–28 px） | 身体定位、专业解剖、安全说明 |
| 卡片/工具标题 | 1.125–1.25 rem（18–20 px） | 当前任务、可能相关肌群 |
| 正文和主要按钮 | 1 rem（16 px） | 说明、定位选项、操作按钮 |
| 次要信息 | 0.875 rem（14 px） | 辅助提示、标签、状态说明 |
| 非关键图注 | 0.75 rem（12 px） | 来源和极短图注，不能承载关键操作 |

核心内容和操作文字不低于 14 px，正文与主要按钮以 16 px 为主。行高按正文约 1.5、标题约 1.2 设置。缩放字体后，卡片允许增高和换行，工具栏可换行，文字不被截断；不得以缩小字体维持一行。

验收以浏览器 200% 放大为准：内容和功能不丢失，无横向页面滚动；局部画布可以在自身容器内平移，但不能把整个页面撑宽。

## 7. 安全说明

安全说明分三层展示，语言保持简短、可执行：

### 可以开始

- 以轻柔、可控制的幅度进入动作。
- 目标感受是轻到中等、稳定的牵拉感；疼痛不是“动作有效”的证明。
- 根据当下活动能力调整幅度和时长，不与示范者幅度比较。

### 立即停止

- 出现锐痛、麻木、电击样感觉、明显头晕或不稳定。
- 出现胸部不适、呼吸异常，或症状向远端扩散。
- 动作过程中症状持续加重，停止后仍不缓解。

### 先接受专业评估

- 近期有明显外伤、肿胀、变形，或无法正常承重/使用该部位。
- 无力或麻木进行性加重，或出现其他令人担心的神经症状。
- 不确定某个动作是否适合已有疾病、术后状态或当前伤情。

页面明确说明：这些信息用于运动教育与风险边界提示，不提供诊断，也不能替代医生或物理治疗师的个体评估。

内容来源边界：动作原则参考项目内《拉伸解剖学》整理内容中关于轻柔牵拉、疼痛不是验证标准、锐痛/麻木/电击样症状应停止等原则；红旗风险和转诊边界属于网站为安全使用补充的通用提示，不标注为书中逐字内容。外部核验遵循 AAOS “运动不应引发疼痛、疑问时咨询医生或物理治疗师”的原则，以及 NICE 关于结合个人能力提供自我管理建议、怀疑严重病理时转诊的原则。

## 8. 状态与数据边界

新增的界面状态包括：

- `explorerMode`：`3d` 或 `anatomy`。
- `anatomySex`：`male` 或 `female`。
- `anatomyView`：`front`、`side` 或 `back`。
- `anatomyZoom`：受最小值、最大值和固定步长约束的数值。

身体区域、肌肉目标和症状仍使用现有状态与 URL 持久化逻辑，避免产生两套选择来源。模式、性别和解剖视角属于观察偏好，不改变动作推荐结果；是否写入 URL 以现有页面的轻量状态约定为准，不为本次改版新增复杂路由。

加载专业解剖失败时，中央舞台显示可恢复的错误提示和“重试”按钮，同时保留右侧全部文字定位控件。图形失败不能阻断用户继续选择动作。

## 9. 可访问性与交互规则

- 模式、性别和视角使用真实按钮或 tab 语义，并提供清晰的选中状态。
- 所有图形点击能力都有键盘可用的文字等价入口。
- 缩放按钮有可读名称，当前缩放比例通过文字显示。
- 颜色不是唯一状态线索；选中态同时使用边框、底色、图标或文字。
- 点击目标不小于约 44 × 44 CSS px。
- 动画遵守系统“减少动态效果”偏好。

## 10. 验收标准

### 功能

- 中央可在 3D 人体和专业解剖间切换，专业解剖不再弹出模态窗口。
- 专业解剖可切换男生/女生和正面/侧面/背面，可放大、缩小、复位。
- 切换观察方式不丢失当前身体区域和肌肉选择。
- 每个已配置肌肉目标都能通过文字按钮选择；图形共用热区时可从候选项选中准确目标。
- 膝、肩、踝图的大号编号不再覆盖肌肉插图。
- 安全说明包含“可以开始、立即停止、先接受专业评估”及非诊断声明。

### 视觉与响应式

- 正文与主要操作以 16 px 为主，核心文字不低于 14 px。
- 桌面端中央舞台是首要视觉焦点，右栏不再重复小人体。
- 手机端按任务顺序纵向排布，无内容裁切。
- 浏览器放大 200% 后，文字、按钮和关键功能仍完整可用，页面无整体横向滚动。

### 验证

- 为模式切换、性别/视角、缩放边界、选择保持、文字兜底入口和安全内容新增或更新自动化测试。
- 运行项目完整测试、构建和 Sites 交付检查。
- 在真实页面分别检查桌面端、手机端和 200% 字体/页面缩放；验证男女正侧背、缩放复位、局部标注与至少一个共用肌肉热区。

## 11. 本次不做

- 不把教育型定位工具描述为医学诊断或精准解剖诊断工具。
- 不引入旧的、授权范围不适合生产分发的 GLB 模型。
- 不改变动作推荐算法、动作内容数据或发布流程。
- 不执行正式发布、群发、删除或批量覆盖。

## 12. 参考依据

- W3C WCAG 2.1，Resize Text：支持文字放大到 200% 且不丢失内容或功能。
- U.S. Web Design System，Typesetting tokens：以 16 px 根字号和离散 `rem` 层级组织字号。
- AAOS，Spine Conditioning Program：锻炼不应引发疼痛，不确定时咨询医生或物理治疗师。
- NICE NG59，Low back pain and sciatica：自我管理和运动建议应结合个人需求与能力；怀疑严重病理时应转诊。
