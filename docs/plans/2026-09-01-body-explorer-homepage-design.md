# MOVE LAB 3D 身体定位首页设计

- 日期：2026-09-01
- 状态：已确认
- 视觉方向：方案 B「身体冒险地图」

## 目标

在现有动作教程前增加一个首页，让用户通过可旋转、可缩放的着装 3D 人体定位不适部位，经过两步安全分流后，查看可能相关肌群、基础建议与对应教程。首页提供教育性运动康复信息，不诊断疾病，不替代医生或物理治疗师的个体评估。

## 已确认约束

- 首页采用深蓝、亮黄、珊瑚红、蓝、绿组成的多巴胺运动配色，延续现有 MOVE LAB 的粗描边、圆角卡片和游戏化语言。
- 人物穿现代运动服，使用自然 A 字站姿；双臂离开躯干约 25–30°，肘部微屈，保证肩、腋下、上臂和肘部可点击。
- 覆盖 7 个核心区域：颈部、肩胛/肩、胸背、腰部、髋臀、膝、踝小腿。
- 定位采用两级结构：先选择大区域，再选择该区域内的具体肌肉或解剖位置；概念图中的浮动圆点不作为实际坐标依据。
- 采用“运动服 / 肌肉地图”双模型切换，不展示裸体特征、骨骼、器官或非必要解剖结构。
- 保留现有 15 个教程、搜索、侧边栏、动作过程图、动作到位图及所有文字内容。
- 用户流程采用两步安全分流，不简化为疾病诊断式的一键结论。

## 核心用户流程

1. 用户进入首页，看到穿运动服的 3D 人体、7 个部位入口和“定位不适”任务提示。
2. 用户通过模型 hotspot 或文字按钮先选择大区域；镜头自动放大该区域并切换到肌肉地图。
3. 与该区域相关的肌群以不同颜色显示，用户点击具体肌群进行多选，再选择酸紧、活动受限、无力、肿胀、刺痛/麻木等感受并完成警示表现判断。
4. 若存在明显警示表现，停止推荐教程，显示专业评估提示。
5. 若适合一般自我练习，结果卡展示可能相关肌群、基础原理、可尝试的方法、停止条件和来源。
6. 用户可随时切回运动服核对原始位置，再返回肌肉地图；观察角度、缩放和已选肌群保持不变。
7. 首页根据部位和感受推荐 2–3 个现有教程；进入教程详情再返回时，保留首页选择状态。

## 页面结构

### 顶部导航

- MOVE LAB 品牌标识。
- 身体定位、动作教程两个主要入口。
- 搜索继续服务于动作、肌肉和常见问题。

### 任务与步骤区

- 使用“选位置 → 选感受 → 得建议”三段进度表达。
- 首次访问显示一句简短说明，避免用户把结果误解为诊断。

### 3D 人体区

- 着装模型为默认视图。
- 支持旋转、缩放、前后观察和重置视角。
- 7 个大区域使用真实 3D hotspot；放大后的具体肌群选择使用网格点击，不再叠加一圈近似定位圆点。
- 选中大区域后，镜头使用该区域预设的相机目标、观察角度和缩放范围自动聚焦；左、右侧区域分别聚焦对应侧，不使用统一居中裁切。
- 聚焦完成后自动切换到肌肉地图；该区域相关肌群同时显示，并使用稳定且可区分的颜色编码。
- 具体肌群通过真实网格点击进行多选；再次点击取消，不限制只能选择一块肌肉。
- 未选相关肌群保持较低亮度的固有颜色；已选肌群提高亮度并增加描边/光晕，同时在文字列表中出现相同色标和选中标记。
- 悬停或键盘聚焦某个肌群时，模型与文字列表同步突出其名称；颜色不是唯一的识别方式。
- 热点绑定模型空间坐标与表面法线，不使用固定屏幕坐标或视觉估算位置。
- 每个热点必须同时校验正面、背面、左右侧面和不同缩放比例，避免旋转后漂移到错误结构。
- 大区域 hotspot、区域相机预设、可选肌肉网格和结果卡必须通过稳定结构 ID 关联，保证选择链路一致。
- 模型切换时保存相机角度与缩放比例。
- 若 WebGL 或模型加载失败，退回静态着装人体图和 7 个文字按钮，完整保留定位与教程推荐流程。

### 评估与结果区

- 第一步显示当前部位和修改入口。
- 第二步允许多选感受，并提供简短安全问题。
- 普通结果使用“可能相关”“可以尝试”等措辞。
- 风险结果不展示训练按钮，只显示停止自练及专业评估建议。
- 每条建议显示资料来源与更新时间。

### 教程推荐区

- 每个区域至少映射 2 个现有动作；数量不足时允许跨区域推荐协同训练。
- 推荐卡继续使用现有教程缩略图、时长、难度和动作详情。
- 首页只做筛选与解释，动作标准仍由现有教程详情页负责。

## 精确定位与肌群多选

| 大区域 | 首版具体定位目标 |
| --- | --- |
| 颈部 | 上斜方肌、肩胛提肌、颈后肌群 |
| 肩胛/肩 | 三角肌区域、冈下肌区域、中下斜方肌、菱形肌、前锯肌 |
| 胸背 | 胸大肌/胸小肌区域、胸椎旁肌群、背阔肌 |
| 腰部 | 腰段竖脊肌、腰方肌区域、侧腹肌群 |
| 髋臀 | 臀大肌、臀中肌、梨状肌区域、髋前侧屈肌群 |
| 膝 | 膝前区、膝内侧区、膝外侧区、膝后区、股四头肌远端 |
| 踝小腿 | 腓肠肌、比目鱼肌、胫骨前肌、跟腱/踝后区 |

- 膝、踝等关节位置按解剖区域定位，不强行命名为单块肌肉。
- 穿衣模型用于选择大区域；自动放大并切换到肌肉地图后，用户直接点击相关肌肉网格。
- 用户可以同时选择同一区域内的多个肌群；结果页按已选结构的并集匹配教程，并优先显示同时覆盖多个已选肌群的动作。
- 膝、踝等关节区域额外提供“关节附近 / 无法确定具体肌肉”选项，避免用户被迫把关节不适归入某块肌肉。
- 具体定位表示用户报告的不适位置，不等同于确定疼痛来源或诊断受损组织。

## 内容与安全边界

- 首页不根据单一部位或感受推断具体疾病。
- 不使用“治愈、纠正、根治、一定有效”等承诺。
- 明显外伤、进行性无力或麻木、严重肿胀或变形、发热伴疼痛等情况进入风险分流。
- 用户运动过程中出现锐痛、麻木、眩晕、明显不稳或症状持续加重时，教程提示停止。
- 动作剂量采用保守起点，并鼓励根据舒适度调整；具体诊疗方案需由合格专业人员评估。

## 3D 资产与交互方案

- 着装人体：使用官方 MakeHuman 导出的 CC0 人体和运动服资产，并在导出后进行网页体积优化。
- 肌肉地图：从 Z-Anatomy CC-BY-SA 4.0 模型中仅导出与 7 个区域相关的肌肉结构，删除器官、生殖结构、骨骼与无关网格，使用中性教育配色。
- 运行时使用 `<model-viewer>` 的相机控制与 hotspot 机制，避免引入完整游戏引擎。
- 两个 GLB 在制作阶段统一站姿、中心点、比例和朝向；分别压缩纹理与网格，并提供海报图。
- 页面保留模型来源与许可证说明，满足署名及 ShareAlike 要求。

## 技术结构

- `HomePage`：首页壳层、导航和状态恢复。
- `BodyExplorer`：模型加载、视角同步、热点与降级展示。
- `AssessmentPanel`：部位、感受和风险分流。
- `RecommendationPanel`：肌群解释、建议、来源和教程推荐。
- `TutorialLibrary`：从现有 `App` 中提取，完整保留当前教程体验。
- `bodyRegions` 数据层：7 个区域、热点坐标、肌群、感受、风险规则、建议、来源及教程 ID 映射。
- `anatomyTargets` 数据层：稳定的结构 ID、所属大区域、前后侧、着装模型坐标、肌肉模型网格名称、中文名称、固定色标和关联教程。
- `regionCameraPresets` 数据层：每个区域及左右侧的相机目标、观察角度、最小/最大缩放和返回全身视图参数。
- 首页选择状态使用 `selectedAnatomyTargetIds` 数组保存多选肌群，并与模型网格、色标列表和教程匹配同步。
- 首页与教程库使用轻量 URL 状态，支持浏览器返回和教程深链接，不引入无必要的路由框架。

## 响应式与无障碍

- 桌面端以中央 3D 人体、左侧步骤、右侧结果为主。
- 移动端将 3D 人体置顶，步骤与结果使用下方抽屉；避免模型手势阻断页面纵向滚动。
- 所有大区域 hotspot 和具体肌群网格都有对应文字按钮，并支持键盘完成同样的多选操作。
- 颜色不是唯一状态提示；选中、风险和完成状态同时使用文字及图标。
- 支持 `prefers-reduced-motion`，减少镜头转动与面板动画。

## 验收标准

- 7 个部位均可通过模型和文字按钮选择。
- 每个大区域均能继续选择具体肌肉或解剖位置，且文字列表可完成同样操作。
- 选择大区域后，镜头准确放大对应侧并自动显示相关肌群；返回全身后可继续选择其他区域。
- 同一区域可以同时选中多个肌群；取消任意一块不会清空其他已选肌群，结果与教程推荐即时更新。
- 相关肌群颜色彼此可区分，选中状态同时具有亮度、描边和文字标记，在色觉受限模式下仍可识别。
- 每个 hotspot 在正面、背面、左右侧面和移动端缩放状态下均指向目标结构，没有悬空、串位或遮挡误点。
- 大区域 hotspot 与放大区域一致；具体肌群网格、颜色列表、已选标签和结果卡名称完全一致，自动化数据测试校验稳定结构 ID 绑定。
- 运动服与肌肉地图切换后保留部位、观察角度和缩放比例。
- 每个普通结果至少推荐 2 个现有教程，且能正确进入详情。
- 风险结果不会出现训练 CTA。
- 浏览器返回后首页状态不丢失。
- 3D 加载失败时，静态降级流程仍可完成定位、分流和教程推荐。
- 桌面与移动布局均无横向溢出，键盘可以完成核心流程。
- 现有 15 个教程、搜索、分类、动作图片切换和警示内容不回归。
- `npm test`、Sites worker 测试和生产构建通过，并完成真实浏览器主流程检查。
